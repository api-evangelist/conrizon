conrizon AG is a German holding company, founded in 2020 and headquartered in Essen, that unites four of Europe's leading Enterprise Content Management (ECM) brands — easy software, PROXESS, HABEL, and Portal Systems (Shareflex), alongside the friendWorks professional-services unit — under one roof.

The group provides legally compliant, audit-proof digital archiving (GDPR, GoBD, eIDAS), document management (DMS), invoice and procure-to-pay (P2P) processing, contract management, and HR/HCM software with automated workflows, plus AI services and connectors for SAP and Microsoft 365 / SharePoint. Solutions are offered cloud-native, in a private cloud, on-premises, or hybrid, and are relied on by more than 8,700 companies and organizations worldwide.

- Website: https://conrizon.com/en/
- Founded: 2020 — Headquarters: Essen, Germany
- Leadership: Andreas Zipser (CEO), Ulrich Edelmann (CFO), Volker Grümmer (CCO)
- Backed by: Battery Ventures

## API surface

conrizon is a corporate ECM software vendor. Its products (easy, PROXESS, HABEL, Shareflex) ship integration APIs privately with on-premises / cloud deployments, but the company publishes **no public developer portal, OpenAPI, or self-serve API surface**. Only the WordPress REST backend of the marketing site is reachable (`/wp-json`). This profile therefore captures verified company identity plus a probed domain-security posture; there are no spec-bearing artifacts to enrich.
